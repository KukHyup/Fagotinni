### 2.3 `lib/features/fingering/domain/basson_fingering_variation.dart` — ✅ реализовано

**Ключевая архитектурная правка плана.** Вариация — это **не** `Set<FingeringKey>` и **не** ячейка сетки, а самостоятельный снимок состояния всех 29 клапанов. Одна нота даёт **список** вариаций (2–3 штуки), `BassonFingeringView` показывает их слайдшоу.

```dart
class BassonFingeringVariation {
  const BassonFingeringVariation._(this._mask);   // 29 бит в одном int
  bool operator [](FingeringKey key) => (_mask >> key.bitIndex) & 1 == 1;
  Set<FingeringKey> get keys;                      // lazy, unmodifiable
  Set<TrillKey> get trillKeys;
  BassonFingeringVariation withKey(FingeringKey, {bool pressed = true});
}

class BassonFingeringVariationBuilder {
  BassonFingeringVariationBuilder holeIndex() => _set(FingeringKey.holeIndex);
  BassonFingeringVariationBuilder thumbBflat() => …
  // 29 цепочечных методов + release()/clear()/build()
}
```

**Почему битовая маска, а не `Map<K, bool>`:** `Map.unmodifiable` на 29 записей — это отдельный объект-обёртка плюс boxed `bool` на каждое значение; чтение идёт через хеш-таблицу. Маска — это **один `int`**, чтение `key => bool` за одну операцию сдвига, без аллокаций, сравнение и `hashCode` — по значению, иммутабельность бесплатна (у `int` нет мутабельных операций). 29 ключей с запасом влезают в 64 бита.

Плата: `bitIndex` привязан к порядку enum. При добавлении ключей перенумеровать нужно только если превысим 64 — сейчас запас 35 слотов.

`FingeringKey` — **29 значений, ровно по числу клапанных component set в Figma** (§1.5.3), сгруппированы 9+4+5+8+3, в комментарии каждого — id набора из макета.

### 2.4 `lib/features/fingering/domain/fingering_table.dart` — не начато

```dart
typedef FingeringTable = Map<ScoredNote, Map<FingeringMode, List<BassonFingeringVariation>>>;
```

- **const Dart-файл**, не JSON: нужен compile-time и юнит-тесты.
- Источник — стандартная таблица аппликатур фагота. Каждую строку сверяем с `Key`-вариантами макета по открытым/закрытым клапанам.
- ⚠️ **`trill` — это НЕ «основная аппликатура + переключение trill-клавины».** По Wikipedia (Bassoon → Technique → Modern fingering): у фагона основная аппликатура ноты обычно **самая сложная** (лучший звук), а trill играют **более простой** альтернативной аппликацией, чтобы быстро чередовать. Значит в таблице для одной ноты: 1 `basic` (сложная, полная) + 1–2 `trill` (простые). Это ровно те самые 2–3 вариации, которые листает слайдшоу.
- Для trill-аппликаций нужно решить, **какая именно клавиша** используется для каждой ноты — их 5 (`F♯`, `E♭`, `G`, `C♯`, `B♭` trill). Это предметная работа, а не вывод из макета.

### 2.5 `test/basson_fingering_variation_test.dart` — ✅ 25 тестов

- уникальность `bitIndex` 0..28, все в пределах 64 бит
- 29 одноклавинучных вариаций попарно различны
- `keys` + `releasedKeys` разбивают весь инструмент (2 + 27 = 29)
- порядок вызовов билдера не влияет на результат (`==` и `hashCode`)
- `withKey` возвращает копию, оригинал не меняется
- `B♭1` = MIDI 34, имена плоские, `fromMidi` round-trip 34..76

### 4.3 Блок ноты = выбор ноты

`2186:4958` (18,634 95×139) — **тап открывает `NotePickerSheet`** (`showModalBottomSheet`):

- сетка чипов `StaffNoteChip` — 12 колонок × N октав, горизонтальный скролл по октавам

- альтернативный вход — лента нот §4.5

> Это и есть «кнопка басового ключа позволяет выбрать ноту».

### 4.4 Переключатель Basic / Trill — это **модификатор игры**

`2176:267` (`mod=On`) / `2176:269` (`mod=Off`), 71×31, Audiowide 24. Тап меняет **подпись** и **режим** (`FingeringMode.basic ↔ .trill`), а не геометрию раскладки.

**Что это значит по существу.** `Basic` — полная аппликатура: все клапаны, которые надо держать для лучшего звука. `Trill` — альтернативная, **более простая** аппликатура, выбранная так, чтобы можно было быстро чередовать соседние ноты (источник: Wikipedia, Bassoon → Technique → Modern fingering — «the simpler fingerings for such notes are used as alternate or trill fingerings, and the bassoonist will use as full fingering one or several of the more complex executions possible, for optimal sound quality»).

Поэтому `mode` **не переключает источник данных**, а выбирает, из какого подсписка листать слайдшоу:

```dart
PageView.builder(
  itemCount: variationsFor(note, mode).length,   // 1 basic, 1–2 trill
  itemBuilder: (_, i) => ValvePainter(variationsFor(note, mode)[i]),
)
```

⚠️ В Figma только переключатель подписи и **ноль** trill-раскладок ([C](consistency.md) §2.7) — то есть содержимое `trill` придётся наполнять с нуля по учебнику. Это самая дорогая содержательная часть F.

### 4.4a Слайдшоу вариаций — **точки страчки не убирать**

`BassonFingeringView` показывает 2–3 вариации одной ноты как карусель. Полоса-точек `@189,633` / `@187,668` из макета — **индикатор позиции карусели**, а не мусор.

⚠️ В плане ранее было записано «точки убрать, смысла не несёт» — **это было неверно**, решение отменено.

- `PageView.builder` с `PageController`
- точки строятся из `variationsFor(note, mode).length`, активная подсвечивается `#37BED0`
- свайп по горизонтали; вертикальный свайп должен уходить родителю
- при смене ноты карусель сбрасывается на 0
- базовая анимация 180 мс, но между вариациями логичнее `AnimatedSwitcher` по **разнице масок** — клапаны плавно гаснут/зажигаются, а не перерисовываются целиком

### 4.5 Лента нот

**Решение:** горизонтальная лента `24,624 354×121 r=14` (страница `Компоненты`), **не** сетка 2×4 — сетка занимает треть высоты и перекрывает клапаны ([C](consistency.md) §2.4).

### 4.6 Зум `+` / `–`

Вторая реализация из макета: Lateef 40 `#FFFFFF` в плашке 30×30, `scale` 1.0 ↔ 1.15 через `Transform`. Полоса-точек **остаётся** — это индикатор карусели (§4.4a), просто переезжает на неё.

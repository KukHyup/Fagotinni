## 1. Проблема

Дизайн и код — два разных приложения по оформлению:

| | Figma | Код |
|---|---|---|
| Акцент | `#37BED0` / `#1B6654` / `#0E9E7D` | `#C4A574` (бронза) |
| Фон | графит `#1E1E20` + градиент, экран `#000` | коричневый `#12100E` |
| Семейств шрифтов | 6 (Audiowide, Aclonica, Montserrat, Inter, Lateef, Rajdhani) + SF Pro | 1 — `Segoe UI` (`theme.dart:32`), **только Windows** |
| Тем | тёмная + светлая | только тёмная |
| Градиенты | 5 | 0 |
| Токены | именованная система | константы в одном классе + типографика инлайн в виджетах |

Ни одна из 5 реализованных фич не свёрстана по дизайну, поэтому переезд темы **не ломает ничего готового** — но ломает каждый новый экран, если отложить.

---

## 2. Решение, которое надо принять

| Вариант | Что делаем | Последствие |
|---|---|---|
| **A. Дизайн (рекомендую)** | Переписать `theme.dart` на холодную бирюзу | 1 день переделки. Новые экраны сразу в дизайне. 5 старых экранов надо пересмотреть визуально, но не переписывать |
| B. Оставить бронзу | Один экран аппликатур в чужой палитре | Экран аппликатур будет выглядет как вставка из другого приложения. Все 35 экранов дизайна придётся перекрашивать в макетах |
| C. Двухтемная «гибридная» | Фаготинни в бронзе, аппликатуры в бирюзе | ❌ Худший вариант: два визуальных языка в одном приложении |

**Фиксируем A.** Остальные планы считают тему решённой.

### 2.1 Что НЕ переносим из дизайна

- `Aclonica 11` — альтернативный дубль подписей навбара, конфликтует с Audiowide (см. [C · Неконсистентности](consistency.md) §2.1).
- `Inter`, `Montserrat`, `Rajdhani` — используются только в заглушках и подписях размеров девайсов, в приложении не нужны.
- Светлая тема — **отдельная задача, вне объёма T** (§6).

## 3. Задачи

### T.1 Вынести токены в файлы

Создать `lib/app/tokens/`:

| Файл | Содержимое |
|---|---|
| `colors.dart` | `FagColors` — палитра §3.1 |
| `typography.dart` | `FagTypography` — textTheme + display-стили |
| `spacing.dart` | `FagSpacing` — 4/8/12/16/20/24/28/32 + `gutter = 24`, `contentWidth = 354` |
| `radii.dart` | `FagRadii` — 8 / 14 / 18 / 34 / 13.575 (навбар) / 37.5 (светлый) |
| `shadows.dart` | `FagShadows` — `effect_91dad7e6`, `effect_e2e20efa`, `effect_a3e1242e`, `effect_0f42c07a`, `effect_33a2fa85` |
| `gradients.dart` | `FagGradients` — 5 градиентов из §3.1 |

`theme.dart` после этого только собирает `ThemeData` из токенов, ноль хардкода. Закрывает `AUDIT.md` P0.4.

### T.3 Шрифты

Подключить **2** семейства (обе OFL, грузятся в репозиторий):

| Семейство | Где в дизайне | Где в коде |
|---|---|---|
| **Lateef 400** | 24 / 36 / 48 / 96 — ноты, цифры пальцев, буквы A–G | ноты на стане, колонка пальцев, заголовок ноты |
| **Audiowide 400** | 11 / 24 — подписи и заголовки навигации | переключатель Basic/Trill, подписи навбара |

`pubspec.yaml:25` → секция `fonts:`. `theme.dart` → `fontFamily: 'Lateef'` по умолчанию, `Audiowide` отдельным стилем. **Убрать** `Segoe UI`. Закрывает P0.3.

⚠️ `SF Pro` в макетах — системный, не грузим.

### T.4 `darkTheme` / `themeMode`

Сейчас `MaterialApp` получает только `theme:` (`app/app.dart`), переключить тему нечем. Минимум для F: `darkTheme: FagotinniTheme.dark()`, `themeMode: ThemeMode.system`. Светлая тема — §6.

### T.5 Миграция существующих 5 экранов

| Экран | Что поменять |
|---|---|
| `practice/practice_screen.dart` | фон, `bronze` → `FagColors.accent`, `cream` → `#FFFFFF` |
| `metronome/metronome_screen.dart` | то же |
| `tuner/tuner_screen.dart` | то же + шкала `inTune/sharp/flat` остаётся смысловой (красный/зелёный) |
| `more/more_screen.dart` | то же |
| `placeholders/placeholder_screen.dart` | то же |

Тексты и раскладку **не трогаем** — это не входит в T.

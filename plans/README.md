## Порядок работ

| # | Шаг | Что делаем | Результат |
|---|---|---|---|
| 1 | **C** §1–§2 | Закрыть конфликты и баги в Figma, принять продуктовые решения | Дизайн пригоден для реализации |
| 2 | **C** §4.1–4.3 | Починить микрофон / метроном / потерю прогресса | Баги, ломающие пользователя |
| 3 | **T** | Переписать `theme.dart`, токены, шрифты | Единый визуальный язык |
| 4 | **N** | Свой навбар, 5 пунктов, вложенная «Практика» | Куда встраивать экраны |
| 5 | **F** §2 | Таблица аппликатур 50×2 | **критический путь** |
| 6 | **F** §3–§4 | Painter'ы и экран | Работающий экран |
| 7 | **F** §5 | Интеграция, тесты, golden | В репозитории |

Шаги 3 и 4 параллельны. Шаг 5 можно начать **до** шага 4 — таблица аппликатур от навигации не зависит.

## Что вне этих планов

Осталось нераспланированным (см. `AUDIT.md` §4, §5):

| Что | Почему не в планах | Куда |
|---|---|---|
| Онбординг | Нет в дизайне вообще — рисовать с нуля | Отдельный план после F |
| Дом / гамма дня | 2 макета, зависит от данных стрика | Отдельный план после N |
| Поиск аппликатур | 2 макета, воронка к F | Включить в F после §4 |
| Награды / статистика | 1 макет | Отдельный план |
| Профиль «Я» | Только иконка | Отдельный план |
| Лента «Мир» / конкурсы | **Нет сетевого слоя** в проекте | Бэклог, требует бэкенда |
| Настройки | ~10% в коде | Расширить N |
| Светлая тема | Нет в коде, есть в `Компоненты #2023:123` | `theme.md` §6 |
| Роутинг, DI, тесты, релиз-подпись | Инфраструктура | P3, `AUDIT.md` §4 |
